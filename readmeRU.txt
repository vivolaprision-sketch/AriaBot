ЧТО ТАКОЕ ARIABOT?
────────────────────
AriaBot — это ассистент автоматизации, разработанный специально
для La Prisión. Он позволяет записывать и воспроизводить
последовательности действий, выполнять автоклик, предотвращать
отключение за бездействие (AFK), отслеживать повышение уровня
и открывать гиды и карты игры, не выходя из игрового экрана.


РЕКОМЕНДАЦИИ ПЕРЕД НАЧАЛОМ РАБОТЫ
────────────────────────────────────
► Запускайте игру в ПОЛНОЭКРАННОМ режиме для оптимальной работы.
  AriaBot должен правильно видеть экран, чтобы обнаруживать
  изображения и выполнять действия в нужном месте.

► Если вы оставляете бота работать в автономном режиме,
  ИГНОРИРУЙТЕ чат игры. Сообщения других игроков могут сместить
  положение мыши или клавиатуры и рассинхронизировать очереди.

► Запускайте AriaBot от имени Администратора (установщик делает
  это автоматически). Если горячие клавиши не реагируют,
  проверьте наличие прав администратора.


УСТАНОВКА
──────────
1. Запустите AriaBot_Setup.exe и следуйте инструкциям мастера.
2. Выберите папку установки (по умолчанию — «Программные файлы»).
3. Необязательно: создайте ярлык на Рабочем столе и/или в меню Пуск.
4. По завершении можно запустить программу прямо из установщика.

Программа автоматически создаёт в папке установки:
  · Secuencias.json  → сохранённые вами очереди
  · hotkeys.json     → настройки горячих клавиш
  · settings.json    → настройки языка
  · templates\       → папка с захваченными изображениями для очередей
  · changelog.txt    → история изменений (загружается при обновлении)
  · _update.bat      → временный файл, появляющийся и исчезающий
                       во время автообновлений (это нормально, не удаляйте)


ГЛАВНОЕ ОКНО
─────────────
Окно разделено на две зоны:

  ЛЕВАЯ ПАНЕЛЬ (боковая)
  · Состояние каждой активной функции в реальном времени.
  · Список настроенных горячих клавиш.
  · Быстрый доступ к Флагам, Гиду и Карте.
  · Кнопка ⚙ Настройки для конфигурации клавиш и языка.

  ПРАВАЯ ПАНЕЛЬ
  · Общие настройки (интервал автоклика, скорость мыши,
    режим одного цикла, запись).
  · Сохранённые изображения → управление шаблонами распознавания.
  · Очереди шагов → запись, редактирование и выполнение макросов.
  · Журнал в реальном времени → запись всех действий программы.


ФУНКЦИИ
────────

1. СТРАЖ УРОВНЯ (F4 по умолчанию)
   Отслеживает чат игры с помощью OCR. Когда обнаруживает
   сообщение «HAS SUBIDO DE NIVEL» жёлтым цветом, останавливает
   все активные функции и автоматически закрывает игру.
   Это предотвращает повышение уровней без применения очков
   телосложения, которое уменьшило бы максимальное здоровье.
   Идеально для фарма без присмотра.

2. ПОСТОЯННЫЙ АВТОКЛИК (F5 по умолчанию)
   Выполняет непрерывные клики, пока активен. Настройте
   интервал в поле «Интервал Автоклика (с)» на верхней панели.
   Нажмите клавишу снова для остановки.

   БЛОКИРОВКА МЫШИ ВО ВРЕМЯ АВТОКЛИКА:
   Включите флажок «Блокировать мышь во время автоклика»
   на панели состояния, чтобы зафиксировать курсор в позиции
   записи на время работы автоклика. Полезно, когда другие
   действия системы могут сдвинуть указатель.

3. ЦИКЛ АНТИ-AFK (F6 по умолчанию)
   Случайным образом периодически перемещает персонажа,
   чтобы игра не отключила вас за бездействие.
   Включите и забудьте.

4. ЗАПИСЬ ОЧЕРЕДЕЙ (F7 по умолчанию)
   · Нажмите F7 для начала записи.
   · Выполните действия, которые хотите автоматизировать
     (клики, клавиши, паузы, движения мыши).
   · Нажмите F7 снова для остановки записи.
   · Очередь сохраняется и готова к выполнению.
   · Можно иметь несколько очередей и переключаться между
     ними через раскрывающийся список.
   · Каждый шаг очереди можно редактировать: изменить время
     ожидания, назначить изображение для проверки,
     переупорядочить или удалить шаги.
   · Можно добавлять статические паузы между шагами
     кнопкой «Добавить Статическую Паузу» рядом с кнопкой
     запуска.

5. ЗАХВАТ ИЗОБРАЖЕНИЯ (F8 по умолчанию)
   Выберите область экрана для сохранения в качестве шаблона.
   Эти изображения используются как условие проверки в шагах
   очередей: бот убедится, что изображение видно на экране,
   прежде чем выполнить этот шаг. Если не обнаружит —
   может повторить попытку или пропустить шаг.
   · Нажмите Escape для отмены захвата без выбора области.
   · Также можно импортировать внешние PNG-изображения
     прямо из панели сохранённых изображений, без захвата экрана.

6. ФЛАГИ (F9 по умолчанию)
   Открывает встроенный Мастер Генератор Флагов v6. Позволяет
   создавать и настраивать флаги игры с более чем 500 вариантами,
   редактор цветов посимвольно, сборщик ника+рамки и прямой
   экспорт кода для файла .inf игры.

7. ГИД ПО ТЮРЬМЕ (F10 по умолчанию)
   Открывает полный гид по игре прямо внутри AriaBot, без
   необходимости выходить или переключать окно. Включает
   категории: Боеприпасы, Кулинария, Химия, Ювелирное дело,
   Навыки, Одежда, Механика, Шитьё, Карлито-Броня и Уровни.
   Источник: www.gentelaprision.es

8. КАРТА ТЮРЬМЫ (F11 по умолчанию)
   Открывает интерактивную карту игры внутри AriaBot с:
   · Масштабированием колесом мыши или кнопками +/−
   · Перетаскиванием для навигации по карте
   · Легендой с переключателями для показа/скрытия слоёв
   · Кнопкой ЦЕНТР для возврата к начальному виду (120%)
   · Правый клик по карте → показывает координаты точки
     (полезно для калибровки)

   ПОИСК КОМНАТ:
   · Введите название любой комнаты в строку поиска
   · Поиск в реальном времени, без учёта диакритических знаков
   · Карта автоматически масштабируется и центрируется
     на найденной комнате
   · Если несколько результатов — навигируйте кнопками ‹ ›
   · Счётчик показывает количество результатов (напр: 1 / 3)
   · Очистите текст для возврата к обычному виду

   Источник: www.gentelaprision.es

9. ОСТАНОВИТЬ ВСЁ (F12 по умолчанию)
   Немедленно останавливает все активные функции: автоклик,
   AFK, страж, выполняющиеся очереди. Кнопка экстренной
   остановки.


ОБЩИЕ НАСТРОЙКИ
────────────────
На верхней правой панели находятся три независимых элемента:

  ИНТЕРВАЛ АВТОКЛИКА (с)
  Введите количество секунд между каждым кликом автоклика.
  Применяется в реальном времени без перезапуска.

  СКОРОСТЬ ПЕРЕМЕЩЕНИЯ МЫШИ В ОЧЕРЕДЯХ
  Ползунок, управляющий скоростью перемещения мыши при
  выполнении очередей. По умолчанию по центру (стандартная
  скорость). Влево — медленнее, вправо — быстрее.

  ОДИН ЦИКЛ ОЧЕРЕДИ
  Если отмечено, активная очередь выполнит один полный цикл
  и автоматически остановится. Без отметки — очередь
  повторяется в непрерывном цикле до ручной остановки.


НАСТРОЙКА ГОРЯЧИХ КЛАВИШ (⚙ Настройки)
─────────────────────────────────────────
Можно изменить любую горячую клавишу на нужную комбинацию:

1. Нажмите кнопку ⚙ Настройки на левой панели.
2. Нажмите кнопку действия, которое хотите изменить.
3. Нажмите нужную клавишу или комбинацию (Ctrl+J, Alt+F, F2…).
4. При конфликте с другим действием программа предупредит вас.
5. Нажмите «Сохранить и Применить» — изменения вступят в силу немедленно.
6. «Восстановить по умолчанию» вернёт клавиши F4–F12.

Настроенные клавиши сохраняются в hotkeys.json и автоматически
загружаются при каждом запуске программы.

ВАЖНО: клавиши, назначенные действиям AriaBot, не записываются
в очереди — они не мешают автоматизации.


СМЕНА ЯЗЫКА (⚙ Настройки)
───────────────────────────
AriaBot доступен на Испанском, Английском, Французском,
Итальянском, Немецком и Русском языках.
Для смены языка:

1. Нажмите кнопку ⚙ Настройки на левой панели.
2. В разделе ЯЗЫК / LANGUAGE выберите ES, EN, FR, IT, DE или RU.
3. Нажмите «Сохранить и Применить».
4. Появится уведомление о необходимости перезапуска.
5. Нажмите «Перезапустить сейчас» для немедленного применения
   или «Перезапустить позже» при следующем запуске.

Выбранный язык сохраняется в settings.json и применяется
автоматически при каждом запуске программы.


ТЕХНИЧЕСКАЯ ПОДДЕРЖКА
──────────────────────
AriaBot включает встроенную форму обратной связи, доступную
по кнопке «Контакт» в нижней части левой панели. Заполните
имя, email и описание проблемы — сообщение будет отправлено
напрямую разработчику.


ОБЛАЧНАЯ ПЛАТФОРМА
───────────────────
AriaBot включает интеграцию с сервером для обмена очередями
с другими игроками:

· Опубликовать Очередь → загружает активную очередь на сервер,
  чтобы другие игроки могли её скачать.
· Обзор Репозитория → скачивает очереди, опубликованные другими
  пользователями, и импортирует их в вашу коллекцию.


ОЧЕРЕДИ — РАСШИРЕННОЕ ИСПОЛЬЗОВАНИЕ
──────────────────────────────────────
· Можно создавать сколько угодно очередей кнопкой «+».
· Каждая очередь сохраняется автоматически при закрытии программы.
· Шаги поддерживают: левый клик, правый клик, двойной клик,
  нажатие клавиши, ввод текста и таймерные паузы.
· Назначение изображения шагу заставляет бота проверять наличие
  этого изображения на экране перед выполнением шага.
· Очереди можно запускать в непрерывном цикле или в одном цикле,
  включив параметр «Один цикл очереди».
· Можно добавлять статические паузы между шагами кнопкой рядом
  с кнопкой запуска.
· Можно импортировать внешние PNG-изображения в панель шаблонов
  без необходимости захватывать их с экрана.


СОЗДАВАЕМЫЕ ФАЙЛЫ И ПАПКИ
───────────────────────────
Все файлы создаются в той же папке, где находится .exe:

  Secuencias.json   → записанные очереди (рекомендуется резервная копия)
  hotkeys.json      → настройки горячих клавиш
  settings.json     → настройки языка
  templates\        → изображения для проверки в очередях
  Mapa.png          → изображение карты (обновляется автоматически)
  changelog.txt     → создаётся/обновляется при получении обновления
  readme.txt        → это руководство (обновляется автоматически)
  _update.bat       → временный файл во время обновлений (удаляется сам)
  AriaBot.new       → временный файл при загрузке обновления
                      (становится AriaBot.exe по завершении)


АВТОМАТИЧЕСКИЕ ОБНОВЛЕНИЯ
───────────────────────────
AriaBot проверяет наличие новой версии при каждом запуске.
Если найдена — предложит обновиться. После подтверждения:
  1. Загружает новую версию в фоне (прогресс виден в журнале).
  2. Загружает обновлённые changelog, readme и Mapa.png.
  3. Автоматически закрывается.
  4. Заменяет исполняемый файл новой версией.
  5. Открывает changelog.txt в Блокноте для ознакомления с изменениями.
Ничего больше делать не нужно. Ваши очереди и настройки сохраняются.
